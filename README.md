# تقارير المقاولين اليومية

تطبيق ويب لمتابعة تقارير اشتراطات السلامة (35 عنصر) والمواد الحرجة لـ 17 مقاول، لكل يوم وشفت.

- الصق رسالة المقاول كما هي، والتطبيق يقرأ المتوفر والناقص تلقائيًا.
- أي عنصر ما عليه ✅ صريحة يُحسب ناقص.
- البيانات محفوظة داخل المتصفح (IndexedDB). خذ نسخة احتياطية من الإعدادات بشكل دوري.

الملفات: `index.html` (التطبيق كامل) + `manifest.json` + `sw.js` + الأيقونات.
